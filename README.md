# دهانات وديكور جيزان

موقع متخصص في تقديم خدمات الدهانات الداخلية والخارجية، ورق الجدران، ديكورات الجبس، والتشطيبات المتكاملة في منطقة جيزان وضواحيها.

## إضافة أعمال جديدة للمعرض

يمكنك استخدام سكريبت `add-work.ps1` بسهولة لإضافة الصور أو مقاطع الفيديو إلى معرض الأعمال:

```powershell
.\add-work.ps1 -Title "تصميم صالة فخمة" -Category "دهانات داخلية" -MediaPath "C:\path\to\image.jpg"
```
